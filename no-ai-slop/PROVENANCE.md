## Local extension (not upstream)

Upstream treats this as an **on-demand editor**: the user pastes a draft, the
skill edits or audits it. Peter Marreck additionally wants these rules to govern
**agent output itself**, continuously, without being invoked.

That always-on obligation lives in the canonical brief
(`AGENTS_concise.md.md` → "Writing style") rather than here, so it loads in every
session. This directory stays a faithful copy of upstream so it can be updated
from it cleanly.
